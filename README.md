# vic3mod – alternatywna historia do Victorii 3

Mod do Victorii 3 ze startem **1 stycznia 1836**, osadzony w alternatywnej historii.

## Punkt rozbieżności

Około 895 roku **Madziarzy nie wchodzą do Kotliny Panońskiej**. Zostają na stepach Etelközu (dzisiejsza południowa Ukraina), gdzie z czasem znikają pod naporem Pieczyngów, Połowców i Mongołów.

Z tego wynika kilka zmian, które razem tworzą świat moda:

- przetrwanie **Wielkich Moraw**,
- **slawizacja Panonii**,
- przetrwanie **Słowian połabskich**,
- **zablokowanie niemieckiej ekspansji na wschód**.

Reszta to łańcuch przyczyn i skutków aż do 1836 roku.
