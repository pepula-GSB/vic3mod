# Flagi Marchii Miśnieńskiej (koncepty)

Miśnia: husyckie lenno Moraw z saksońskim węglem. Płaskie flagi 3:2 (SVG 1536×1024) i podgląd PNG, generowane skryptem `generuj_flagi.py`. Podgląd całości: [arkusz.png](arkusz.png).

**Lew miśnieński** (czarny, z czerwonym językiem i pazurami) jest wycięty z herbu od autora moda: [../emblematy/lew_misnienski.png](../emblematy/lew_misnienski.png). Do flagi rewolucyjnej jest też wersja złota: [../emblematy/lew_misnienski_zloty.png](../emblematy/lew_misnienski_zloty.png).

| Plik | Ustrój |
|---|---|
| 1_marchia | Marchia (start, lenno Moraw): złote pole z czarnym lwem, czarne pasy u góry i dołu |
| 2_republika | Republika: czerń i złoto dzielone pionowo, bez lwa |
| 3_teokracja | Teokracja husycka: złoto z czarnym lwem, czarny pas u dołu z białym kielichem |
| 4_rewolucja | Miśnia rewolucyjna: czerwień, złoty lew, czarny pas u dołu, złota gwiazda w rogu |
