# Flagi Królestwa Halicko-Wołyńskiego (koncepty)

Halicz: unickie królestwo z Lwowem, Haliczem, Łuckiem i Mołdawią. Płaskie flagi 3:2 (SVG 1536×1024) i podgląd PNG, generowane skryptem `generuj_flagi.py`. Podgląd całości: [arkusz.png](arkusz.png).

**Lew halicki** jest wycięty z herbu od autora moda: [../emblematy/lew_halicki.png](../emblematy/lew_halicki.png) (złoty) i [../emblematy/lew_halicki_niebieski.png](../emblematy/lew_halicki_niebieski.png) (błękitny).

| Plik | Ustrój |
|---|---|
| 1_krolestwo | Królestwo (start): złoty lew na błękicie, złote pasy u góry i dołu |
| 2_republika | Republika: błękit nad złotem (barwy halickie), lew w kantonie |
| 3_teokracja | Teokracja unicka (metropolita lwowski w unii z Rzymem): złoto i biel pionowo w barwach papieskich, błękitny lew |
| 4_rewolucja | Rewolucja: czerwień, przy drzewcu złota gwiazda, a pod nią złoty lew, błękitny pas u dołu |
