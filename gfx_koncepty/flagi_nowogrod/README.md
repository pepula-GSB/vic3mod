# Flagi Republiki Nowogrodzkiej (koncepty)

Nowogród: prawosławna republika kupiecka od Estonii po Alaskę. Płaskie flagi 3:2 (SVG 1536×1024) i podgląd PNG, generowane skryptem `generuj_flagi.py`. Podgląd całości: [arkusz.png](arkusz.png).

**Godła** pochodzą z flagi od autora moda: tron z dwoma niedźwiedziami ([../emblematy/nowogrod_tron_niedzwiedzie.png](../emblematy/nowogrod_tron_niedzwiedzie.png)) i ryby ([../emblematy/nowogrod_ryby.png](../emblematy/nowogrod_ryby.png), wersja biała: [../emblematy/nowogrod_ryby_biale.png](../emblematy/nowogrod_ryby_biale.png)).

| Plik | Ustrój |
|---|---|
| 1_republika | Republika (start, wiece i Rada Panów): biel nad błękitem, tron z niedźwiedziami, ryby na błękicie |
| 2_teokracja | Rządy arcybiskupa nowogrodzkiego (realnie przewodniczącego Radzie Panów): purpura ze złotą linią zamiast błękitu, tron bez ryb |
| 3_rewolucja | Nowogród rewolucyjny: czerwień nad błękitem, złota gwiazda, białe ryby (rybacy i flisacy) |
