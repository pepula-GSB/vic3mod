# Flagi Łużyc (koncepty)

Łużyce Serbołużyczan: husyckie lenno Moraw. Płaskie flagi 3:2 (SVG 1536×1024) i podgląd PNG, generowane skryptem `generuj_flagi.py`. Podgląd całości: [arkusz.png](arkusz.png).

**Godła:**
- złoty mur z blankami Górnych Łużyc, rysowany wektorowo w skrypcie;
- czerwony wół Dolnych Łużyc, wycięty z herbu od autora moda: [../emblematy/wol_luzycki.png](../emblematy/wol_luzycki.png).

| Plik | Ustrój |
|---|---|
| 1_margrabstwo | Margrabstwo (start, lenno Moraw): łużycka trójbarwa błękit-czerwień-biel z tarczą: czerwony wół przed złotym murem na błękicie |
| 2_republika | Republika: sama łużycka trójbarwa |
| 3_teokracja | Teokracja husycka: biel z czerwonym wołem, czarny pas u dołu z białym kielichem |
| 4_rewolucja | Łużyce rewolucyjne: czerwień, złoty mur z blankami u dołu, złota gwiazda |
