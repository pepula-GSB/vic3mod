# Flagi Cesarstwa Bułgarsko-Romejskiego (koncepty)

Cesarstwo z Konstantynopolem, Muntenią, Dobrudżą i Despotatem Epiru i Albanii. Płaskie flagi 3:2 (SVG 1536×1024) i podgląd PNG, generowane skryptem `generuj_flagi.py`. Podgląd całości: [arkusz.png](arkusz.png).

**Godła** według wzorów od autora moda:
- **krzyż z czterema krzesiwami** (flaga tetragrammatyczna Paleologów): krzesiwo wycięte jako maska ([../emblematy/krzesiwo_bizantyjskie_maska.png](../emblematy/krzesiwo_bizantyjskie_maska.png)), krzyż rysowany w skrypcie;
- **tamga IYI** rodu Dulo (znak dawnych chanów bułgarskich), rysowana wektorowo.

| Plik | Ustrój |
|---|---|
| 1_cesarstwo | Cesarstwo (start): romejski krzyż z krzesiwami, na skrzyżowaniu czerwona tamga IYI, czyli unia Rzymu i Bułgarii |
| 2_republika | Republika: na wzór flagi greckiej, dziewięć pasów czerwień-złoto, w kantonie złoty krzyż |
| 3_rewolucja | Rewolucja: wzór republiki, w kantonie złoty młot zamiast krzyża, na złotych pasach hasło *ΠΡΟΛΕΤΑΡΙΟΙ ΟΛΩΝ ΤΩΝ ΧΩΡΩΝ, ΕΝΩΘΕΙΤΕ!* („Proletariusze wszystkich krajów, łączcie się!”) |
