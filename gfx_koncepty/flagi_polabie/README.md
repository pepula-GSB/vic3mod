# Godła i flagi państw połabskich (koncepty)

## Stodorania: herb z Trygławem

[../emblematy/tryglaw_herb.png](../emblematy/tryglaw_herb.png) (źródło SVG obok): trójgłowy Trygław w aureoli na czerwonej tarczy gotyckiej. Kult Trygława był ośrodkiem Brenny (Brandenburga), stolicy Stodoran, więc pasuje jako godło Stodoranii. Popiersie jest wycięte z ilustracji przesłanej przez autora moda: [../emblematy/tryglaw_popiersie.png](../emblematy/tryglaw_popiersie.png).

**Uwaga prawna:** to współczesna ilustracja konkretnego artysty, nie herb ani domena publiczna. Do publikacji moda potrzebna jest zgoda autora rysunku. Bez niej trzeba narysować własnego Trygława w tym duchu.
