# Flagi Księstwa Pruskiego (koncepty)

Prusy są **katolickim** państwem bałtyckim (Tuwangste, Warmia z Fromborkiem), w bloku z Mazowszem. Płaskie flagi 3:2 (SVG 1536×1024) i podgląd PNG, generowane skryptem `generuj_flagi.py`. Podgląd całości: [arkusz.png](arkusz.png).

**Wzór bazowy i godło** pochodzą od autora moda: czerń i czerwień z białymi lamówkami oraz biała tarcza z postacią Prusa. Postać jest wycięta z tła w [../emblematy/prus.png](../emblematy/prus.png).

| Plik | Ustrój |
|---|---|
| 1_ksiestwo | Księstwo (start): wzór od autora moda |
| 2_republika | Republika: same pasy, bez godła |
| 3_teokracja | Teokracja katolicka (biskupi warmińscy): złoty pas środkowy, złoty krzyż nad tarczą |
| 4_rewolucja | Prusy rewolucyjne: czerwień z czarnym pasem u dołu, czarna gwiazda w białym obrysie |
