# Flagi Wielkiego Księstwa Litewsko-Ruskiego (koncepty)

Prawosławna Litwa-Ruś z Wilnem i Kijowem. Płaskie flagi 3:2 (SVG 1536×1024) i podgląd PNG, generowane skryptem `generuj_flagi.py`. Podgląd całości: [arkusz.png](arkusz.png).

**Godła** według wzorów od autora moda:
- tarcza z trzema Pogoniami pod koroną, wycięta z flagi: [../emblematy/herb_litwa_rus.png](../emblematy/herb_litwa_rus.png);
- złoty krzyż podwójny (krzyż Pogoni), rysowany wektorowo.

| Plik | Ustrój |
|---|---|
| 1_ksiestwo | Wielkie Księstwo, monarchia (start): zieleń-biel-czerwień, tarcza z trzema Pogoniami i koroną na środku |
| 2_republika | Republika: zieleń, czerwony pas i biel, złoty krzyż podwójny |
| 4_rewolucja | Litwa-Ruś rewolucyjna: czerwień z zielonym pasem u dołu, biały jeździec Pogoni ([../emblematy/pogon_bialy.png](../emblematy/pogon_bialy.png)), złota gwiazda w rogu |
