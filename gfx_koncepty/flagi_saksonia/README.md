# Flagi Królestwa Saskiego (koncepty)

Saksonia Welfów: protestanckie państwo frontowe nad Łabą, ze stolicą w Brunszwiku, a później w Hanowerze. Płaskie flagi 3:2 (SVG 1536×1024) i podgląd PNG, generowane skryptem `generuj_flagi.py`. Podgląd całości: [arkusz.png](arkusz.png).

**Koń saski** to biały wspięty rumak z flagi od autora moda, zamieniony na płaską sylwetkę: [../emblematy/kon_saski.png](../emblematy/kon_saski.png). Źródło było bardzo małe (~80 px), więc sylwetka jest wygładzona. Do finalnej grafiki przyda się większy plik.

| Plik | Ustrój |
|---|---|
| 1_krolestwo | Królestwo (start, Welfowie): czerwień ze złotymi pasami u góry i dołu, biały koń |
| 2_republika | Republika: biel-czerwień-biel, koń na czerwonym pasie |
| 3_zjednoczenie | Saksonia na czele zjednoczonych Niemiec: czerń-czerwień-złoto, tarcza z koniem |
| 4_rewolucja | Saksonia rewolucyjna: czerwień, biały koń, biała gwiazda w rogu |
