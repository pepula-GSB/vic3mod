# Flagi Królestwa Morawskiego (koncepty)

Morawy Mojmirowiców: serce kościoła husyckiego, suweren Czech, Śląska, Łużyc i Miśni. Płaskie flagi 3:2 (SVG 1536×1024) i podgląd PNG, generowane skryptem `generuj_flagi.py`. Podgląd całości: [arkusz.png](arkusz.png).

**Orzeł morawski** (szachowany, w koronie) jest wycięty z flagi od autora moda: [../emblematy/orzel_morawski.png](../emblematy/orzel_morawski.png). Źródło jest małe (~180 px), powiększone 3×. Do finalnej grafiki potrzebny większy plik.

| Plik | Ustrój |
|---|---|
| 1_krolestwo | Królestwo (start, Mojmirowice): orzeł na błękicie, wzór od autora moda |
| 2_republika | Republika: żółto-czerwone barwy morawskie, błękitny panel z orłem przy drzewcu |
| 3_teokracja | Teokracja husycka: jak królestwo, czarny pas u dołu z małym białym kielichem |
| 4_rewolucja | Morawy rewolucyjne: czerwień, pas szachownicy przy drzewcu, złota gwiazda |

Flaga z samym kielichem w [../flagi_husyci/](../flagi_husyci/) (`3_morawy`) zostaje jako wersja do zestawu bloku husyckiego.
