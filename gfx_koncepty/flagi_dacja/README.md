# Flagi Dacji i jej regionów (koncepty)

Płaskie flagi 3:2 (SVG 1536×1024) i podgląd PNG, generowane skryptem `generuj_flagi.py`.

| Plik | Państwo / ustrój |
|---|---|
| panonia_1_republika | Republika Panońska (katolicki zachód Dacji między Karpatami a Cisą, jeśli się oderwie): błękit, czerwień i żółć (wzór od autora moda) |
| panonia_2_monarchia | Królestwo Panonii: ta sama trójbarwa co republika |
| panonia_3_teokracja | Teokracja unicka (biskupi Timișoary w unii z Rzymem, obrządek wschodni): trójbarwa jak republika, mały biały krzyż trójbelkowy na czerwonym pasie |
| panonia_4_rewolucja | Panonia rewolucyjna: trójbarwa jak republika, na środku biała gwiazda |

Podgląd: [panonia_arkusz.png](panonia_arkusz.png).
